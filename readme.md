# Nexora Landing Page

A fictional static landing page called Nexora, a fictional company that offers software and technology services.

## About

The page introduces Nexora and showcases its services, projects, company information, and contact section. It is built with HTML and CSS.

## Technologies

- HTML
- CSS

## Project Structure

- `index.html` - Main landing page
- `css/` - Stylesheets for layout, components, variables, and responsive design
- `assets/images/` - Images and logos used on the page

## Run Locally

Open `index.html` in a web browser. No build step or package installation is required.
